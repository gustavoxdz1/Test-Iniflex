# Teste Técnico - Iniflex

Projeto desenvolvido em Java 17 para o teste prático de seleção.

## Tecnologias Utilizadas
- **Java 17**
- **Maven**
- **JUnit 5** (Testes Unitários) OBS: Apenas adicionei esses testes como diferencial ass:Gustavo

## Funcionalidades
- Cadastro e manipulação de funcionários e pessoa.
- Formatação de valores monetários e datas (`pt-BR`).
- Agrupamento por funções (`Map` / `Stream API`).
- Filtros por aniversário, ordenação alfabética e cálculo de maior idade.
- Cálculo de totais e salários mínimos equivalentes.
- Validação de regras de negócio com tratamento de exceções.
